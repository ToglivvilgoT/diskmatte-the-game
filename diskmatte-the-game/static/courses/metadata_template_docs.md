# Template for Courses Metadata Files

## File layout

Each course is its own file:

static/courses/<course_slug>.json

## Course schema

Each file is a single course object with the following format:

```json
{
  "name": "String",
  "description": "optional String",
  "learning_sets": [
    {
      "name": "String",
      "slug": "SlugField",
      "kind": "optional String, default course_book",
      "description": "optional String"
    }
  ],
  "topics": [
    {
      "title": "String",
      "slug": "SlugField",
      "description": "optional String"
    }
  ]
}
```

`name` is always required on a course, a learning set, and a topic.
`course_slug` is extracted from file name.
`learning_sets` and `topics` may be empty lists or omitted.

### order

`order` on learning sets and topics is not read from the metadata. It is
autogenerated from 1 and up, matching the order the objects appear in their list.

### is_active

`is_active` is not read from the metadata. Every course, learning set, and topic
present in the metadata is always synced as active (`is_active = true`). It is
only ever set to `false` by the sync itself, when an object is missing from the
metadata (see below).

## Updating

- If the metadata for a course, learning set, or topic differs from the existing
  database entry, update the existing entry with the new values.
- If metadata fields are missing that the database object has, the database
  object is updated and those fields cleared to their default.

## Missing metadata

If an existing course, learning set, or topic in the database is no longer present
in the metadata files, mark it as `is_active = false` and print a warning. It is
never deleted by the sync.

## Errors

If a course, learning set, or topic object is missing a required field
(`name`/`title` or `slug`), print an error message detailing what is missing on
what object, skip that object, and continue with the rest of the file.

If a learning set or topic references a course that could not be created due to
missing required fields, skip it and print an error message.
